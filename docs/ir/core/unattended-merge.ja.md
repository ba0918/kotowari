# 人を待たずにマージする

[English](unattended-merge.md) | 日本語

工程の skill が、1つの依頼を仕様の承認からマージまで人を待たずに通すやり方を扱う。計画を書かなくなった cycle が何を入力にするか、人がマージを確認するかを決める線、マージのしかた、その回について記録するもの。
