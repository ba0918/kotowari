# Glossary

English | [日本語](CONTEXT.ja.md)

Terms used in the specification IR of kotowari-markdown-view (view). view is a rendering engine that does not know kotowari, and the terms here are the words of view's input and output.

| Term | Meaning | Source |
|---|---|---|
| render input | Everything view receives for one rendering. Consists of a sequence of `document` entries, the `reference table`, the `table of contents`, a language tag, the `UI text` and the `other languages` | docs/decision/records/2026-10-02-whole-picture.md#A25, docs/decision/records/2026-10-02-whole-picture.md#A42, docs/decision/records/2026-10-05-overview-index.md#A10, docs/decision/records/2026-10-05-overview-index.md#A33, docs/decision/records/2026-10-05-localization.md#A9, docs/decision/records/2026-10-05-localization.md#A20, docs/decision/records/2026-10-05-localization.md#A32 |
| document | The source of one `page` within the `render input`. Has a name, a title, the opening lead `part`, the sequence of opening `part` entries that follow the lead, and the sequence of `section` entries. Not a file | docs/decision/records/2026-10-02-whole-picture.md#A42, docs/decision/records/2026-10-02-whole-picture.md#A68, docs/decision/records/2026-10-02-whole-picture.md#A82, docs/decision/records/2026-10-04-overview-on-public-api.md#A10 |
| section | One "## " heading within a `document` together with the sequence of `block` entries under it. Has a true-or-false value telling whether it is stale | docs/decision/records/2026-10-02-whole-picture.md#A39, docs/decision/records/2026-10-02-whole-picture.md#A68 |
| block | The unit of the contents of a `section`. Either a chunk of Markdown text or a `part` | docs/decision/records/2026-10-02-whole-picture.md#A42 |
| part | A unit of drawing of a fixed kind. Has the name of its kind and a value that fits the schema of that kind. Not called a "block" or a "component" | docs/decision/records/2026-10-02-whole-picture.md#A11, docs/decision/records/2026-10-02-whole-picture.md#A36, docs/decision/records/2026-10-02-whole-picture.md#A51 |
| part schema | A JSON Schema that declares, for each kind of `part`, the shape of its contents. view holds and publishes it, and it is the authority on the shape of parts | docs/decision/records/2026-10-02-whole-picture.md#A45, docs/decision/records/2026-10-02-whole-picture.md#A46, docs/decision/records/2026-10-02-whole-picture.md#A47 |
| reference | A string written in a field named "refs" or "ref" within the value of a `part` | docs/decision/records/2026-10-02-whole-picture.md#A66 |
| reference table | A mapping from the string of a `reference` to display name, body and status. Built outside view and passed to it. Not called a "link table" | docs/decision/records/2026-10-02-whole-picture.md#A25, docs/decision/records/2026-10-02-whole-picture.md#A51, docs/decision/records/2026-10-02-whole-picture.md#A65, docs/decision/records/2026-10-02-whole-picture.md#A67 |
| page | The combination of the name and the contents of one file that view outputs. view writes no files; it returns the sequence of pages | docs/decision/records/2026-10-02-whole-picture.md#A26, docs/decision/records/2026-10-02-whole-picture.md#A56, docs/decision/records/2026-10-02-whole-picture.md#A22, docs/decision/records/2026-10-02-whole-picture.md#A82 |
| table of contents | Part of the `render input`: the outermost `contents group`, which decides the order and nesting of each `page` on the listing page. Not called a "map" or an "index" | docs/decision/records/2026-10-05-overview-index.md#A7, docs/decision/records/2026-10-05-overview-index.md#A9, docs/decision/records/2026-10-05-overview-index.md#A15, docs/decision/records/2026-10-05-overview-index.md#A33 |
| contents group | A bundle inside the `table of contents`. Has a title, an optional one-line description, and items that list in order names of a `document` and nested `contents group` entries. Not called a "category" or a "folder" | docs/decision/records/2026-10-05-overview-index.md#A4, docs/decision/records/2026-10-05-overview-index.md#A9, docs/decision/records/2026-10-05-overview-index.md#A10 |
| outline | The sequence of the headings of each `section` of a `page`, drawn on the `page` of a `document`. Each entry links to its `section`. Not called a `table of contents` | docs/decision/records/2026-10-05-overview-page-reading.md#A1, docs/decision/records/2026-10-05-overview-page-reading.md#A2, docs/decision/records/2026-10-05-overview-page-reading.md#A12, docs/decision/records/2026-10-05-overview-page-reading.md#A18, docs/decision/records/2026-10-05-overview-page-reading.md#D1 |
| UI text | Part of the `render input`: a mapping from keys to strings. Every text view writes into a page that does not come from another part of the `render input` is taken from here. Not called "labels" or "translations" | docs/decision/records/2026-10-05-localization.md#A5, docs/decision/records/2026-10-05-localization.md#A9 |
| other languages | Part of the `render input`: the sequence of places where the same `page` is drawn in other languages. Each entry has the name of the language and the path to that place relative to the place of this sequence of `page` entries | docs/decision/records/2026-10-05-localization.md#A20, docs/decision/records/2026-10-05-localization.md#A32 |
