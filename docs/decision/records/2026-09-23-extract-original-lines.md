# 壁打ちの記録: 抽出の値に元の行をそのまま使う

## Context

mds の`抽出`で、複数の行にわたる値の字下げと空行が崩れていた。段落の1行目だけ字下げが消え、2行目からは残り、段落どうしの間の空行は消える。`箇条書き`・`フィールド行`・`文`・`節`・`項目`のどれも同じ崩れ方をする。行で読むときは、`文`の行と行の間に元の文書に無い空行が足される。

原因は1つで、段落を元の文書から切り出すときに段落の開始位置（字下げの後ろ）から取り、前後の空白を落としていたこと。誰かが決めた規則ではない。[A11（mds-spec）](./2026-09-21-mds-spec.md#A11) の「元の行をそのまま保つ」にも、字下げをすべて除く読み方にも合わない。

Position: 承認済み（2026-09-23）。

## 実測（f160459 の mds values、段落の読み方）

| 入力 | 出力 |
|---|---|
| `- 親` / 空行 / `  続き` | `- 親\n続き` |
| `- ` / `  親` / 空行 / `  続き` | `- \n親\n続き` |
| `- 親` / `  二行目` / 空行 / `  続き` | `- 親\n  二行目\n続き` |
| `- 状態: 承認` / `  値の二行目` / 空行 / `  状態の続き` | `承認\n  値の二行目\n状態の続き` |
| `- 親` / 空行 / `  - 子` / 空行 / `    子の続き` | `- 親\n  - 子\n子の続き` |

行で読むとき、`文`の2行 `段落1の一行目` / `  段落1の二行目`（空行なし）は、`文`の値で `段落1の一行目\n\n段落1の二行目` になっていた。

## Agreements

- A1 `抽出`の値に入る行は、元の文書の行をそのまま使う。字下げと、値の途中の行の末尾の空白を消さない。値の末尾の空白と空行は除く
  - why: [A11（mds-spec）](./2026-09-21-mds-spec.md#A11) の「抽出した値から元の行に戻せる」を、`箇条書き`の1行目だけでなく値の全体で成り立たせる。場所ごとに扱いが変わる形を残さない
  - rejected: 一覧の中身の字下げをすべての行から除く（CommonMark の中身の読み方）。A11 とぶつかり、子の`箇条書き`の行だけ字下げを残す例外が要る
  - decided_by: 利用者

- A2 値が始まる位置は`ノード`ごとに決める。`箇条書き`はその行のマーカーから（A11 のまま）、`フィールド行`は "名前:" の後の空白の後から、`文`は段落の最初の空白でない文字から。2行目からは行の先頭から取る
  - why: A1 の「元の行をそのまま」を、`ノード`が持つ値の範囲に当てはめたもの。フィールド行の名前やマーカーの前の字下げは値ではない
  - decided_by: 利用者（推奨を採用）

- A3 複数の部分から成る値（`箇条書き`の lead 段落・`継続段落`・子の`箇条書き`、`フィールド行`の lead 段落と`継続段落`、`文`の並び、`節`の本文、`項目`の本文）は、含める部分の間に元の文書で空行があれば空行1つで、無ければ改行1つでつなぐ。含めない部分（`表`、`コードブロック`、宣言済みの子の`フィールド行`など）の行は抜き、抜いた跡や元の文書で続いていた空行は空行1つにまとめる。空白だけの行は空行として扱う
  - why: 範囲の元の行から含めない行を抜いた形にすれば、部分の種類ごとのつなぎ方の規則が要らない。今は`文`どうしだけ空行、ほかは改行、`継続段落`どうしは空行と、場所ごとに違っていた
  - rejected: 部分ごとに切り出して改行1つでつなぐ（今のやり方）。部分の中には空行が残り、部分の間では消える
  - decided_by: 利用者（推奨を採用）

- A4 マーカーだけの行の後の lead 段落と`継続段落`の間は、A3 のとおり元の文書の空行が残る。この形のためのつなぎ方を別に持たない（TODO の ID 63）
  - why: lead 段落と`継続段落`の間には元の文書で必ず空行がある。A3 がそれを残すので、形ごとの規則は要らない
  - rejected: どの形でも lead 段落と`継続段落`を改行1つでつなぐ。A1 と A3 を決める前に一度選んだが、元の段落の区切りが値から消える
  - decided_by: 利用者

- A5 `導かれる値`を宣言して行ごとに要素を作る`文`の`要素の値`は、今のまま前後の空白を取り除いた行の文字にする（[A57（ir-engine）](./2026-09-22-ir-engine.md#A57)）。元の行は`生の行`で取る
  - why: 値が1行なので、字下げを取っても行どうしの関係は崩れない。元の行を`生の行`で取れるので、値と`生の行`の役割分担として説明できる。値も字下げ付きにすると`生の行`と同じ文字になり、分けている意味が無くなる
  - decided_by: 利用者（推奨を採用）

- A6 A1〜A3 は`読み方`に依らない。行で読むときも、`文`の行の間に元の文書に無い空行を足さない
  - why: 規則は元の文書の行と空行だけで決まり、読み方が変えるのはどの行がどの`ノード`になるかだけ。行で読むとき`文`の行ごとに空行を足していたのは、段落どうしを空行でつなぐ規則を1行ずつの`文`に当てた結果で、元の文書に無い
  - decided_by: 主セッション（A1 と A3 の統一の指示から導いた）

- A7 区切り文字を宣言した`フィールド行`は、区切る対象を lead 段落の値だけにし、`継続段落`は区切った末尾の要素に A3 のつなぎ方で付ける。区切った要素の前後の空白は今のまま取り除く
  - why: [A50（mds-spec）](./2026-09-21-mds-spec.md#A50) の「継続段落を分割に含めない」構造はそのまま残し、つなぎ方だけ A3 に揃える
  - decided_by: 主セッション（A1 と A3 の統一の指示から導いた）

## Revisions

- [A50（mds-spec）](./2026-09-21-mds-spec.md#A50) の「継続段落は分割した末尾の要素に改行を挟んで付ける」を A7 で改める。つなぎ方は A3 に従い、元の文書の空行が残る
- A4 は、最初に「lead 段落と`継続段落`を改行1つでつなぐ」で決めかけたものを、A1〜A3 を決めた後に置き換えたもの
