# ガイドと全体像の役目

## Context

ガイドは製品を使う人向けの使い方の文書で、全体像は話題ごとに今の状態と予定を描くページである。全体像が見せるものには「使う人から見てどう動くか」が入っていて（[whole-picture A1](./2026-10-02-whole-picture.md#A1)）、単位も機能1つで（[whole-picture A20](./2026-10-02-whole-picture.md#A20)）、古さの検出もガイドの印と同じ仕組みなので、同じ機能の説明を2つの文書で保守することになる。
ローカライズの壁打ちで全体像も言語ごとに作ることにしたので（[localization A10](./2026-10-05-localization.md#A10)）、被りは言語の数だけ増える。このリポジトリ自身の文書を訳す前に決めると未決にした（[localization U1](./2026-10-05-localization.md#U1)）。

Position: 第2ラウンドで用語集（A5）、境目の例（A6）、進め方（A7）を決め、木は尽きた。用語集を直し、照合で前からの出典の引き忘れが見つかった REQ-core-302 に出典を足した（3回目で裏付けの無い項目は0件）。承認待ち。

## Agreements

第1ラウンド（2026-10-05）

- A1 この壁打ちでは、kotowari を使う人がガイドと全体像にそれぞれ何を書くかという役目の分け方を決める。このリポジトリ自身の文書を訳す作業はこの壁打ちを待たずに進めてよい。
  - why: このリポジトリは全体像を使っておらず（設定に "overview" が無く元データが0件）、訳す作業で被りの分だけ量が増えることは今は無い
  - decided_by: 利用者（推奨を採用）
- A2 全体像の読み手は製品を作る人（壁打ちをした本人、実装役、レビュー役）、ガイドの読み手は製品を使う人とする。
  - why: 全体像は実装者、ガイドは利用者が見るので視点が全く違う（利用者の言葉）
  - decided_by: 利用者
- A3 ガイドと全体像は両方残し、答える問いで書き分ける。ガイドは「どう使うか」（コマンド、設定、出力の読み方、手順、例）を書き、決定の経緯や予定と未決の状態を書かない。全体像は「何が決まっていて、なぜか、何が予定で何が未決か」（判断のつながり、決定と予定と未決の札、流れ）を書き、使い方の手順を書かず、振る舞いは判断の結果として短く示すだけにする。
  - why: 読み手（A2）が違い、同じ機能でも答える問いが違うので、書き分ければ同じ説明を2か所で保守しなくて済む
  - rejected: 全体像をやめてガイドに寄せる（判断のつながりと予定と未決を見せる場所が無くなる）。ガイドをやめて全体像に寄せる（全体像は手元で描く HTML で GitHub で読めず、ページの外へリンクしない）
  - decided_by: 利用者（推奨を採用）
- A4 書き分けの指針は kotowari スキルの references（全体像の書き方とガイドの書き方）に書き、IR の要求にはしない。
  - why: ある節が使い方か判断かを機械で判定する方法は無く、検査にすると仕組みが問題より大きくなる
  - decided_by: 利用者（推奨を採用）

第2ラウンド（2026-10-05）

- A5 用語集の「ガイド」に読み手は製品を使う人、「全体像」に読み手は製品を作る人であることを書き、whole-picture A3 にこの記録の A2 への superseded_by を付ける。
  - why: 今の用語集は全体像の読み手を「人間」としか書いておらず、A2 の違いが用語から読めない
  - decided_by: 利用者（推奨を採用）
- A6 書き分けの指針には境目の例を入れる。工程の流れの図（実装役が記録を書き、レビュー役が記録を書き、changes が通る）は判断の結果としての振る舞いなので全体像に置いてよく、コマンドの書き方や選択肢の例はガイドに置き、全体像では機能の名前に触れるだけにする。
  - why: 「振る舞いを短く示す」と「使い方の手順」の境目は、例が無いと書き手ごとにぶれる
  - decided_by: 利用者（推奨を採用）
- A7 この変更（skill の references の文、用語集の2行、whole-picture A3 へのリンク）は、承認の後に手順書と cycle を回さず主セッションが直接直して1本の PR にし、照合記録は実装側を主セッション、レビュー側を別の席が書く。
  - why: コードは変わらず数十行の変更で、手順書と cycle の費用に見合わない
  - decided_by: 利用者（推奨を採用）

## Revisions

- A2 は [whole-picture A3](./2026-10-02-whole-picture.md#A3)（読み手は壁打ちをした本人だけ）を、製品を作る人（本人、実装役、レビュー役）に置き換えた。
- A3 は [whole-picture A1](./2026-10-02-whole-picture.md#A1) の「使う人から見てどう動くか」を、判断の結果としての振る舞いを短く示すことに読み替え、使い方の手順はガイドに任せるものにした。
