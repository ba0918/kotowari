# ローカライズと配色の切り替え

## Context

紹介ページ（site/）は日英の切り替えを持つが、そこからリンクするガイドと README は日本語だけで、英語の読み手は紹介ページの先で離れる。
kotowari の利用者も自分の言語で IR とガイドを書くが、全体像のページの UI の文字（"見直していない節" など）と `lang` の属性は日本語に固定されている。
どちらから進めるか、訳の置き場、訳の古さの検出を、文書のページの壁打ちで未決にした（[U1](./2026-10-05-overview-page-reading.md#U1)）。
明るい配色とダークを読み手が切り替えるか（[U2](./2026-10-05-overview-page-reading.md#U2)）も、どのページにもスクリプトを入れない決まり（[REQ-view-018](../../ir/view/navigation.md#REQ-view-018)）と合わせてここで決める。

Position: 木は尽きた。IR を書き、仕様の敵対的レビューの指摘を D2 で、照合の1回目と2回目の指摘を出典の追加と D3 で直した。3回目の照合で残った2件（REQ-core-339 の出典に A26 と A39、list の sides の並び順）は出典と D3 に足して直し、4回目の照合はしていない。利用者が kemi で承認した（2026-10-05、コメントなし）。PR #14 で実装し、main にマージした。
