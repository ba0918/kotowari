# ADR-0001: テストの印は `@kotowari[ID, ...]`

- 状態: 承認済み（2026-09-13）
- 日付: 2026-09-13
- 判断の記録: `brainstorm/records.md` の A5、A14、A34（A34 は A39 で問い合わせのある言語に限った）

## 状況

要求とテストの対応を機械で数えるには、テストがどの項目を確かめるかをテストの側に書く必要がある。
利用者の言語は分からないので、言語に依存しない書き方が要る。

## 決定

判断の記録の A14 と A34（A39 で改めた後）のとおり。

## 理由

- コメントの中の1語だけを探すので、コメント記号の違いを見ずに済み、言語に依存しない
- `@spec` は他の道具とかぶる可能性があるので `@kotowari` にする（利用者）

## 却下した案

- `@spec[...]`: 他の道具とかぶりうる

## 結果

印は利用者のテストコードに入る。後から形を変えると、利用者のテストをすべて書き換えることになる。
