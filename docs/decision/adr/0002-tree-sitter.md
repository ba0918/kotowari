# ADR-0002: テストは tree-sitter で見つけ、言語ごとの問い合わせを同梱する

- 状態: 承認済み（2026-09-13）
- 日付: 2026-09-13
- 判断の記録: `brainstorm/records.md` の A5、A24、A26、A36、A39、R3（A15 と A16 は A24 で改めた）

## 状況

「ID の付いていないテスト」を挙げるには、コードの中のどこがテストかを知る必要がある。
言語に依存しない方法が望ましいが、「テストである」の判定は言語ごとに違う。

## 決定

判断の記録の A24、A26（`test` は同梱に固定し設定は足す分だけ、と A49 で明確にした）、A39 のとおり。

## 理由

- 正規表現は万能ではなく、意図しない検出やバグが起こる（利用者）。構文木なら、印がどの関数に属するかの範囲の取り方が確実になる
- tree-sitter は広い範囲の言語の文法を持つので、文法の側は大半がどうにかなる（利用者）。ただし「テストである」の判定は言語ごとの問い合わせが要り、言語依存は消えない。そこで問い合わせを kotowari が同梱し、言語を足すときは問い合わせのファイルを足す
- 何をテストと数えるかは採用しているライブラリで変わり、断言できない（利用者）。`#[test]` だけを確実な既定にし、それ以外はプロジェクトごとの設定に書く

## 却下した案

- 設定に書く正規表現でテストの定義の行を見つける: 万能でなく、意図しない検出が起こる

## 結果

plan の段で tree-sitter 本体と文法 crate の版の組み合わせが取れなければ、黙って正規表現に落とさず brainstorm に戻す（A50。利用者の「無理なら正規表現で妥協する」はこの意味）。
問い合わせの無い言語では、「テストのない要求」だけを挙げ、「ID の付いていないテスト」は挙げられない。
