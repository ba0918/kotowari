# 言語ごとの全体像と UI の文字

[English](overview-languages.md) | 日本語

設定の言語の一覧の言語ごとに全体像のページを書くこと、描画のエンジンに渡す言語と UI の文字（全体像のページに kotowari が書く、元データにも仕様にも無い文字）、設定の "labels" から UI の文字を決めることとその誤り、ほかの言語のページで参照の本文をどこから取るかを決める。言語の一覧と対の読み方は[言語の一覧は、設定の languages で決める](translation-pairs.ja.md#言語の一覧は設定の-languages-で決める)から始まる対の話題で、渡されたものを view がどう描くかは[ページの言語](../view/languages.ja.md)で決める。

## 全体像は、言語の一覧の言語ごとに、その言語の側から書く

状態: 実装済み

### 問題

全体像の UI の言語だけを直しても、英語の紹介ページから仕様やガイドへ進んだ読み手が日本語に当たる問題は解けない。国籍の違う利用者が、同じプロジェクトで全体像を読む場面も解けない。言語ごとの読み手が、それぞれ自分の言語のページを読め、リンクだけでほかの言語へ移れるようにしたい。

### 決めたこと

"kotowari overview build" と "kotowari overview serve" は、言語の一覧の言語ごとに、その言語の側の全体像の元データと目次からページを描く。先頭の言語のページは全体像のページの置き場（".kotowari/cache/overview/"）に、ほかの言語のページは ".kotowari/cache/overview/<言語タグ>/" の下に、同じ名前で書く（ページの名前は[overview build は、毎回すべてを描き、中身の違うファイルだけを書き、作られなくなったファイルを消す](overview-commands.ja.md#overview-build-は毎回すべてを描き中身の違うファイルだけを書き作られなくなったファイルを消す)）。言語が1つのときは、その言語のページだけを全体像のページの置き場に書き、言語のディレクトリを作らない。

ある言語のページの古い節は、その言語の側の元データのガイドのマーカーから求める。

### 見送った案

- 全体像は1人の利用者向けのまま、設定の言語1つで描き、公開する資料の訳は別に扱う。英語の読み手が途中で日本語に当たる問題が残る。

### 確認すること

- C-core-ovlang-1 言語の一覧が "ja" と "en" のとき、overview build は "a.html" と "en/a.html" を書き、"en/" の下のページは英語の側の元データの文で描かれる
- C-core-ovlang-2 言語が3つのとき、言語ごとの置き場に、その言語の側の目次の題名を見出しにした一覧のページが書かれる
- C-core-ovlang-3 言語の一覧が "ja" だけのとき、言語のディレクトリは作られず、一覧は "index.html" に書かれる

## 描画のエンジンには、ページの言語、その言語の UI の文字、ほかの言語の名前とページの置き場を渡す

状態: 実装済み

### 問題

view は kotowari を知らない描画のエンジンなので、UI の文字の既定を view と kotowari の2か所に持つと食い違う。また、読めない言語のページに来た読み手でも、自分の言語の名前なら、自分の言語のページへのリンクを見つけられる。

### 決めたこと

ある言語のページを描くとき、描画のエンジンに、その言語タグと、その言語の UI の文字の一式と、ほかの言語ごとの名前とその言語のページの置き場への相対パスを渡す。ほかの言語の名前は、その言語の UI の文字の "language_name" から取る（その言語自身で書いた名前になる）。

### 確認すること

- C-core-ovlang-4 言語ごとのページの "html" の要素に、その言語の言語タグの lang の属性が付く
- C-core-ovlang-5 言語の一覧が "ja" と "en" で、"labels.ja.language_name" が "日本語" のとき、"a.html" には "en/a.html" への "English" のリンクが、"en/a.html" には "../a.html" への "日本語" のリンクがある

## UI の文字は、英語を kotowari が持ち、ほかの言語は設定の labels に書く

状態: 実装済み

### 問題

利用者が書いた文字を kotowari が訳すことはできず、kotowari の持ち物は view が自分で書く文字だけである。設定を書くのは LLM で人は書かないので、kotowari が言語を限定する理由は無い。欠けた鍵を英語で埋めると、1枚のページに2つの言語が混ざる。全体像を使わないプロジェクトにも、ガイドの対の切り替えの行に書く言語の名前のために UI の文字が要るので、置き場は全体像の設定の下に置けない。

### 決めたこと

kotowari が中に持つ UI の文字は、英語だけにする。英語の UI の文字は、kotowari の英語の文字に、設定の "labels.en" に書いた鍵の値を上書きしたものにする。英語のほかの言語の UI の文字は、設定の最上位の "labels.<言語タグ>" の値そのものにする。言語の一覧が無ければ、英語の UI の文字で描く。

UI の文字の鍵は次の表のとおりにする。数を入れる文字の "{n}" は、描くときに数に置き換わる。

| 鍵 | 使う所 | 数を入れる |
|---|---|---|
| language_name | 切り替えの行と、全体像のほかの言語へのリンクに書く、その言語の名前 | いいえ |
| index_link | 目次に名前の無い全体像のページから、一覧へのリンク | いいえ |
| pages | 一覧の目次の群の、全体像の数 | はい |
| stale_sections | 一覧の古い節の数 | はい |
| open_items | 一覧の、札が open の項目の数 | はい |
| planned_items | 一覧の、札が planned の項目の数 | はい |
| stale_mark | 古い節の見出しの近くのマーカー | いいえ |
| outline_stale | アウトラインの古い節のマーカー | いいえ |
| superseded | 置き換え済みの参照のマーカー | いいえ |
| deferred | 後回しの参照のマーカー | いいえ |
| compare_before | compare の部品の、前の列の見出し | いいえ |
| compare_after | compare の部品の、後の列の見出し | いいえ |
| compare_why | compare の部品の、理由の列の見出し | いいえ |
| state_decided | status の札 decided の表示 | いいえ |
| state_planned | status の札 planned の表示 | いいえ |
| state_open | status の札 open の表示 | いいえ |
| state_dropped | status の札 dropped の表示 | いいえ |

### 見送った案

- kotowari が英語と日本語の訳を中に持ち、その2つだけを受け付ける。訳を確かめられる言語に絞る理由は、LLM が書くなら成り立たない。
- 言語の名前だけを "languages" の側に持ち、UI の文字は全体像の設定の下に残す。UI の文字の置き場が2つに割れる。

### 確認すること

- C-core-ovlang-6 "labels.en.pages" だけを "{n} docs" にすると、一覧の目次の群の数は "<数> docs" の形で描かれ、ほかの UI の文字は kotowari の英語の文字のままになる
- C-core-ovlang-7 英語のほかの言語の UI の文字は、"labels.<言語タグ>" に書いた値そのものになる

## UI の文字の設定が欠けているか、数の入れ方が違えば、設定の誤りで停止する

状態: 実装済み

### 問題

欠けた鍵を英語で埋めると、1枚のページに2つの言語が混ざる。数と言葉の並びは言語で変わるので、数の入る所を文字の中に1つだけ示す必要がある。

言語の一覧に無い言語の "labels" と、"labels.en" の表に無い鍵での停止を落とすと、言語タグや鍵の書き間違いが、どのページにも使われないまま黙って残る。この2つで止める理由は、記録に残っていない。

### 決めたこと

次のときは、設定の誤りで停止する。

- 言語の一覧の英語のほかの言語に、"labels.<言語タグ>" が無いか、表の鍵のどれかを欠いている
- 英語のほかの言語の "labels.<言語タグ>" か "labels.en" に、表に無い鍵がある
- "labels" に、言語の一覧に無い言語タグの鍵がある
- 数を入れる鍵の値が、"{n}" をちょうど1つ含まない（"labels.en" を含む）

### 確認すること

- C-core-ovlang-8 言語の一覧が "ja" だけで、"labels.ja" に "stale_mark" の鍵が無いと、設定の誤りで停止する
- C-core-ovlang-9 英語のほかの言語の "labels.<言語タグ>" に表に無い鍵があると、設定の誤りで停止する
- C-core-ovlang-10 数を入れる鍵の値に "{n}" が無いか、2つあると、設定の誤りで停止する
- C-core-ovlang-12 "languages" の鍵が無く（英語だけ）、"labels.ja" があると、設定の誤りで停止する
- C-core-ovlang-13 "labels.en" に表に無い鍵があると、設定の誤りで停止する

## ほかの言語のページでは、参照の本文をそのページの言語の側の決定の文書から取る

状態: 実装済み

### 問題

全体像の部品の参照は、決定の見出しか確認することの ID を指す（[全体像の元データは、決定の文書を指す](languages-and-guides.ja.md#全体像の元データは決定の文書を指す)）。決定の文書も言語の対で持てる（[決定の文書も、多言語の対で持てる](languages-and-guides.ja.md#決定の文書も多言語の対で持てる)）。参照で開く本文は、そのページの読み手が読める言語でなければ役に立たない。訳の無い本文をほかの言語のページで開くと、その言語の読み手には読めない文になる。

### 決めたこと

ある言語のページで、決定を指す参照の本文は、その決定の文書の、そのページの言語の側にある同じ決定から取る。参照に何を書くかは[部品の中の参照は、refs と ref の欄に書く](overview-data.ja.md#部品の中の参照はrefs-と-ref-の欄に書く)で、本文に何を出すかは[参照の表には、参照ごとに参照先の本文を入れる](overview-commands.ja.md#参照の表には参照ごとに参照先の本文を入れる)で決める。

### 確認すること

- C-core-ovlang-11 言語が2つで決定の文書が対のとき、決定を指す参照の本文は、先頭の言語のページでは先頭の言語の側から、ほかの言語のページではその言語の側の同じ決定から取られる
