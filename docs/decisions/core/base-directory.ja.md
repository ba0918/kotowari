# 基準のディレクトリ

[English](base-directory.md) | 日本語

kotowari が相対パスの基準にするディレクトリをどう決めるかと、その基準からの相対で読み書きするパスの扱いを扱う。設定ファイルの読み方そのものは[設定](config.ja.md)の話題で、対象の OS は[対象の OS は Linux と macOS で、Windows ではパスの区切りの正規化だけを約束する](cli-environment.ja.md#対象の-os-は-linux-と-macos-でwindows-ではパスの区切りの正規化だけを約束する)で決める。

## 相対パスの基準は、上に向かって探した最初の .kotowari/ のあるディレクトリにする

状態: 実装済み

### 問題

設定ファイルの値と出力のパスは相対パスで書くので、どこからの相対かを決める必要がある。この探し方を選んだ理由と、"--config" で基準を動かさないことにした理由は残っていない。

### 決めたこと

相対パスの基準は1つにする。kotowari は、カレントディレクトリから上に向かって ".kotowari/" のディレクトリを探し、最初に見つかったディレクトリを基準のディレクトリにする。

| 順 | 条件 | 基準のディレクトリ |
|---|---|---|
| 1 | カレントディレクトリから上に向かって、".kotowari/" のディレクトリのあるディレクトリが見つかる。".kotowari" という名前のファイルは無視して、さらに上に進む | 最初に見つかったディレクトリ |
| 2 | 1 で見つからない | カレントディレクトリ |

"--config" は、読む設定ファイルを変えるだけで、基準のディレクトリを変えない。

### 確認すること

- C-core-base-1 下のディレクトリで "kotowari check" を実行すると、上にある ".kotowari/" のディレクトリが基準になり、指摘の "path" はそこからの相対になる
- C-core-base-2 カレントディレクトリより上のどこにも ".kotowari/" が無ければ、カレントディレクトリが基準になる
- C-core-base-3 途中のディレクトリに ".kotowari" という名前のファイルがあっても、それを無視して、さらに上の ".kotowari/" のディレクトリを基準にする
- C-core-base-4 "--config" でどこにある設定ファイルを指しても、基準のディレクトリは変わらない

## 設定ファイルの値のパスと、出力の "path" は、基準のディレクトリからの相対にする

状態: 実装済み

### 問題

設定ファイルに書いた置き場のパスと、指摘に出すパスを、何からの相対にするかを決める必要がある。カレントディレクトリでなく基準のディレクトリからにした理由は残っていない。

### 決めたこと

kotowari は、設定ファイルの値のパスを、基準のディレクトリからの相対パスとして読む。出力の "path" も、基準のディレクトリからの相対パスにする。出力の "path" は、[正規化](#設定ファイルの値のパスは比べる前と出力の前に正規化する)した置き場と文書名を "/" でつないで作る。

### 確認すること

- C-core-base-5 サブディレクトリで実行しても、設定ファイルに書いた置き場は、基準のディレクトリからの相対として読まれる
- C-core-base-6 出力の "path" は、正規化した置き場と文書名を "/" でつないだものになる

## 設定ファイルの値のパスは、比べる前と出力の前に正規化する

状態: 実装済み

### 問題

同じ場所を指すパスでも、書き方は1通りではない（末尾の "/"、先頭の "./"、"a/.." など）。書いたままの文字で比べると、置き場を "a/../a/b" のように書いたとき、その置き場の中のファイルが置き場の外にあると判定された。比べる相手のパスは既に ".." を畳んでいて、置き場の側だけ畳まないので食い違っていた。

### 決めたこと

kotowari は、設定ファイルの値のパスを、比べる前と出力の前に、次のように正規化する。

- 末尾の "/" と先頭の "./" を除く
- 途中の "/./" と、連続する "/" を、1つの "/" に畳む
- "\\" を "/" に直す
- "a/.." を畳む。畳む相手の無い ".." は残し、基準のディレクトリの外を指すパスのままにする

### 確認すること

- C-core-base-7 末尾の "/"、先頭の "./"、途中の "/./"、連続する "/" が除かれるか畳まれ、"\\" が "/" に直る
- C-core-base-8 設定ファイルの置き場の値に "a/.." があれば畳んでから比べ、畳む相手の無い ".." は残す
