# Glossary

[English](CONTEXT.md) | 日本語

kotowari-markdown-view（view）の決定の文書で使う用語を置く。view は kotowari を知らない描画のエンジンで、ここの用語は view の入力と出力の言葉である。

| Term | Meaning |
|---|---|
| 描画の入力 | view が1回の描画で受け取るものの全体。`文書`の並びと`参照の表`と`目次`と言語タグと`UI の文字`と`ほかの言語`からなる |
| 文書 | `描画の入力`の中の1つの`ページ`の元。名前、題名、冒頭の lead の`部品`、lead に続く冒頭の`部品`の並び、`節`の並びを持つ。ファイルではない |
| 節 | `文書`の中の "## " の見出し1つとその下の`ブロック`の並び。古いかどうかの真偽を持つ |
| ブロック | `節`の中身の単位。Markdown の文章の塊か`部品`のどちらか |
| 部品 | 種類の決まった描画の単位。種類の名前と、その種類のスキーマに合う値を持つ。ブロック・コンポーネントとは言わない |
| 部品のスキーマ | `部品`の種類ごとに中身の形を宣言する JSON Schema。view が持って公開し、部品の形の正とする |
| 参照 | `部品`の値の中の、名前が "refs" か "ref" の欄に書いた文字列 |
| 参照の表 | `参照`の文字列から、表示名、本文、状態への対応。view の外で作られて渡される。リンク表とは言わない |
| ページ | view が出す1つのファイルの名前と中身の組。view はファイルを書かず、ページの並びを返す |
| 目次 | `描画の入力`の一部で、一覧の`ページ`の並びと入れ子を決める、いちばん外側の`目次の群`。地図・索引とは言わない |
| 目次の群 | `目次`の中の束。題名、省いてよい一行の説明、`文書`の名前と`目次の群`を順に並べた項目を持つ。カテゴリ・フォルダとは言わない |
| アウトライン | `文書`の`ページ`に描く、その`ページ`の`節`の見出しの並び。各項目はその`節`へのリンクになる。`目次`とは言わない |
| UI の文字 | `描画の入力`の一部で、鍵から文字列への対応。view がページに書く文字のうち、`描画の入力`のほかの部分から来ないものはすべてここから取る。ラベル・翻訳とは言わない |
| ほかの言語 | `描画の入力`の一部で、同じ`ページ`をほかの言語で描いた置き場の並び。1件は言語の名前と、その置き場へのこの`ページ`の並びの置き場からの相対パスを持つ |
