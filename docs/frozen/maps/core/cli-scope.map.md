## 迷った判断と、どう決めたか

- 消す範囲の安全の細部（`safety-dropped.md` の8）は、同じ細部が overview-commands の話題（31）にあり、振る舞いが見えるのはそちらなので、この話題では戻さずリンクにした。overview-commands の担当がそちらで戻すかは、この話題の作業では確かめられない（同時に別の作業者が確定している）。そちらで戻らなければ、この話題の決めたことに「その下のファイルはどれも自分が作ったものとして扱い、今回作らなかったものを消す」を足し、C-core-scope-4 を置いて req_core_293_any_other_file_under_the_cache_is_removed を当てる。

- REQ-core-101 には確認することを置かなかった。元の確かめ方は「出力が LLM の読みやすい形か」を見るもので、それは「出力の形」の話題の決定を確かめることになる。工程や方針の決定として、確認することの無い決定にした。
- A75 は LLM の裁定だが、A28 で利用者が禁止を維持すると決めたので、禁止そのものを利用者の決定として残した。消す範囲の解釈（A80）は LLM の細部なので、安全に関わる落とした細部に挙げた。
- C-core-scope-1 の "HOME" と "TMPDIR" はテストの作り方の細部だが、元の場面（EX-core-042）に名前があり、利用者から見える環境変数の名前なので残した。
