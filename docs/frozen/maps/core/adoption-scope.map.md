## 迷った判断と、どう決めたか

- 「同じ規則で値や文言だけが違う振る舞いは、1行にまとめて決定表の候補にする」を実装済みのまま残した。この決定は、まとめることと決定表の候補にすることだけを書くので、今の skill の文で通る。決定表は決定の文書でも「決めたこと」の中の表として残る。行が何の候補かは、利用者の答えで決まり、skill の文と違うので、別の「提案」の決定「一覧の1行は、決定1つの候補にする」に分けた。
- 利用者の答えで、前の下書きの「利用者に聞くこと」の2つが決まった。問い1: 一覧の1行は決定1つの候補にする。問い2: 候補の数による見直し（"limits.requirements" と比べる決まり）は消す。
- 「一覧の1行は、決定1つの候補にする」の問題には、前の推奨に付けた理由を書かず、「理由は記録に残っていない」と書いた。答えに理由が付いていないためである。
- 範囲の外の振る舞いを「判断の記録にも書かない」ことは、行にしないことの帰結として決定の文にしなかった。
- ある既存のプロジェクトの名前と、その話題の名前、ファイルの名前は書かず、何が起きたかと数だけを書いた。
