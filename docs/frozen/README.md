# 凍結した古い形の文書

ここにあるのは、仕様を[決定の文書](../decisions/core/decision-documents.md)の形へ切り替える前の、古い形の文書である。今の決まりの根拠として読まない。編集しない。

- `ir/`: 切り替える前の IR。話題ごとに、今の決定の文書の置き場（`docs/decisions/`）へ書き直してある
- `maps/`: 書き直した話題ごとの対応表。古い ID と新しい確認することの ID の対応と、書き直すときに落とした細部の一覧

`kotowari check` はこの木を読まない。リポジトリの `.ignore` で、検索の道具が既定で読み飛ばすようにしてある。
