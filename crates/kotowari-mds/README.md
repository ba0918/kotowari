# kotowari-mds

This package owns the `kotowari-mds` binary.
Its `check`, `values` and `ast` commands keep their existing text/JSON and exit-code contracts.
Use `cargo install --path crates/kotowari-mds --bin kotowari-mds` from the source repository.
For an application API, use `kotowari-markdown-schema` for memory operations or `kotowari-markdown-schema-io` for loading.
